## 真实 7B 冒烟

三个变体使用同一 5,000 帧索引，其中 1,977 条是回程动作监督，包括可见导航 734 条、T1 四档合计 1,243 条。每个变体最多运行一轮，训练进程预算 3,600 秒。闭环使用独立的 5 格可见金柱场景，按水平距离不超过 3 格计成功。统计的可解码动作要求完整动作标签、合法的控制 token 和两个相机轴。全部 1,977 个教师动作通过这一格式检查。

三个变体共享公开 JARVIS-VLA-7B 骨干与动作 tokenizer。视觉编码器冻结，LLM 的注意力与 MLP 投影使用 rank 64 LoRA，启用梯度检查点。仅回程动作 token 计入损失。无记忆用官方两帧历史，长窗口用八帧历史，空间记忆保留两帧历史并以真值位姿写入 32×32×8 网格，读出 32 个 token 拼接到输入前端。[训练与模型配置](../code/minemem/t1_train.py) · [空间记忆](../code/minemem/t1_spatial.py)

长窗口的首次 BF16 运行在九张图像的冻结视觉编码中耗尽显存，空间记忆首次运行在预编码历史帧时出现同样的显存瓶颈。将视觉编码限制为每组三张图，保留解码器的完整历史与原有图像分辨率。小型 Qwen2-VL 视觉模型对五张不同尺寸图像的分组结果与原拼接前向在指定容差内相等。修正后长窗口和空间记忆均进入真实 BF16 优化。[视觉编码与模型](../code/minemem/t1_model.py)
