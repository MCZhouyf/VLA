## 2. 测试一 · 前缀敏感性

每条轨迹在返回首步保持当前位姿不变，分别改变历史位姿、历史视觉配对和标准化后的视觉输入。读出采用 Frobenius 相对变化 `‖干预前缀 − 原前缀‖ / ‖原前缀‖`。门槛要求每个条件在全部 20 个验证轨迹上均达到 10%。

| 干预 | 初始化最小值 / 均值 | 训练后最小值 / 均值 | 通过数（初始化 / 训练后） |
| --- | ---: | ---: | ---: |
| 历史位姿绕当前点旋转 90° | 24.91% / 27.69% | 79.63% / 107.53% | 20/20 / 20/20 |
| 打乱历史视觉与原位姿的对应 | 45.21% / 60.23% | 35.13% / 51.07% | 20/20 / 20/20 |
| 清零标准化视觉 | 120.49% / 123.70% | 45.27% / 58.29% | 20/20 / 20/20 |

被比较的前缀范数相同但方向可以相反，所以相对差允许超过 100%。通过敏感性验收意味着三类历史干预确实改变读出。解码实验进一步检查哪种变化影响航点预测。 [初始化逐例](phase3e-memory-20261125-G8bBJisL/probe-recheck/sensitivity_initial.json) · [训练后逐例](phase3e-memory-20261125-G8bBJisL/probe-recheck/sensitivity_trained.json)

| 范数 | 每 token 平均 L2 | 32 token 的 Frobenius 范数 |
| --- | ---: | ---: |
| 旧空间读出，20 条同批历史 | 270.330 | 1529.216 |
| LLM 普通词表输入，151,643 行 | 0.673720 | 约 3.94（用输入行 RMS × √32 估算） |
| 新空间读出，初始化与训练后 | 0.673720 | 3.811 |

旧前缀每 token 平均约为普通 LLM 输入的 **401 倍**。实际词表全表均值为 0.671920，普通行 RMS 为 0.696010。新前缀以普通行的均值为校准目标。 [词表范数测量](phase3e-memory-20261125-G8bBJisL/cache/embedding_norms.json)

## 3. 测试二 · 航点和金柱可解码性

输入为冻结视觉特征与当前和历史真值位姿，不接 LLM。原教师下一航点只用于标签，航点和金柱相对方向各分 8 类，航点距离在 5 和 15 格处分为三档。“打乱位姿”把历史姿态重新分配给按时间保留的视觉帧，并重新计算路线读出。另报告保留路线几何、只打乱视觉索引的对照。

各单元格依次为**下一航点方向 / 航点距离 / 金柱方向**准确率。

| 距离 | 验证状态数 | 空间记忆 | 仅当前帧 | 打乱位姿对应 |
| --- | ---: | --- | --- | --- |
| 10 格 | 96 | 88.5% / 92.7% / 92.7% | 79.2% / 83.3% / 82.3% | 53.1% / 60.4% / 32.3% |
| 30 格 | 48 | 100% / 100% / 93.8% | 89.6% / 100% / 81.2% | 60.4% / 47.9% / 29.2% |
| 60 格 | 48 | 100% / 100% / 95.8% | 91.7% / 97.9% / 87.5% | 66.7% / 43.8% / 41.7% |
| 100 格 | 48 | 93.8% / 100% / 97.9% | 95.8% / 100% / 85.4% | 62.5% / 58.3% / 64.6% |
| 合计 | 240 | **94.2% / 97.1% / 94.6%** | 87.1% / 92.9% / 83.8% | 59.2% / 54.2% / 40.0% |

两个方向任务在每个距离档都达到 80%。独立测试集空间组为 **97.1% / 98.3% / 98.3%**。仅当前帧的验证总体航点方向率达 87.1%，返回首步为 4/20。教师后续状态已大多朝向下一个路点，因此总体准确率具有强烈的朝向先验。空间组在首步为 **13/20**，30/60 格各 4/4，100 格仅 1/4。独立测试的首步，空间组为 16/20，仅当前帧为 2/20，仅打乱视觉为 8/20。逐场对照有 14 场只有空间组预测正确，2 场空间组和当前帧组均正确，4 场均错误。这些数字来自第二版布景的独立轨迹。

验证集的“正前方”航点标签占 202/240（84.17%）。按八个方向类别等权计算召回率，空间、当前帧、打乱位姿和仅打乱视觉分别为 63.69%、35.28%、36.86%、61.09%。100 格验证首步的三个方向错误中，两例偏差为 90°，一例为 45°。实机分层选路测试比整体分类准确率更直接检查起步决策。

保留路线几何、仅打乱视觉时，验证总体为 **93.8% / 95.4% / 92.5%**，返程首步航点为 10/20。结合打乱位姿的明显下降，第二版布景中主要可解码信号仍是路线几何。视觉选择的收益需要用同路两候选、金柱位置可交换的闭环试验测量。 [汇总与门槛判定](phase3e-memory-20261125-G8bBJisL/probe-recheck/summary.json) · [验证逐条预测](phase3e-memory-20261125-G8bBJisL/probe-recheck/validation_predictions.json) · [独立测试逐条预测](phase3e-memory-20261125-G8bBJisL/probe-recheck/test_predictions.json)

## 5. 正式阶段 A 的实现

正式 T1 v3 使用 `FirstArrivalArena`。出生点远离两处围挡，初始画面需通过金柱投影范围内的颜色检查。回程每一步读取生命和位姿，先进入干扰柱 3 格半径立即失败。教师、转 180 度、扫视、找结构、按真实历史折返和回到起点都使用相同的步数预算和评分逻辑。冻结种子以固定随机序列平衡左右两侧的金柱归属。

控制器输入以当前位姿表达所选航点。路线沿教师折线前看 6 格，文本提示固定使用 10° 和 1 格分辨率。DART 以 20% 概率插入 1–3 步随机转向或停顿，监督始终保留教师纠正动作，训练时以 0.5 概率丢弃历史动作。普通和 DART 的首个实机 10 格归档均已验证提示逐帧对齐，DART 的 259 个回程步中有 97 个扰动步。

正式调度先通过 CPU 验收，再冻结训练、验证、测试和 DART 索引。GPU 6 从已通过近距门槛的共享 LoRA 初始化，正式训练完成后，两卡在四档分别运行 30 个真值航点闭环。四档均达到 80% 后再进入预测航点阶段。 [正式场景](../code/minemem/t1_phase3e.py) · [航点表示](../code/minemem/t1_waypoint.py) · [阶段 A 调度](../code/minemem/t1_phase3e_stage_a.sh)
