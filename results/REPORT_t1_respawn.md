## 布景命令与判定

每回合用 MineStudio 的 `CommandsCallback` 关闭自然生成、清除场内非玩家实体、固定白天、关闭日夜和天气循环并清空天气。沿用 v4 的和平难度。配置记录实际命令、重生平台和可选效果。每个世界在相对金柱向 x、z 各偏移 384 格的位置加载重生区域，用石块和空气命令建立安全平台，再执行 `/spawnpoint @p x y z`。重生点到金柱和外出路径各节点均超过 150 格，地标和干扰柱的位置不变。

| 布景目的 | 命令 |
| --- | --- |
| 关闭刷怪并清除已有实体 | `/gamerule doMobSpawning false`、`/kill @e[type=!player]` |
| 固定白天和晴天 | `/time set day`、`/gamerule doDaylightCycle false`、`/gamerule doWeatherCycle false`、`/weather clear` |
| 隔离重生点 | `/forceload add`、`/fill` 石块与空气、`/spawnpoint @p` |

MineStudio 每步提供 `info["health"]` 和累计 `info["custom"]["deaths"]`。未发生过死亡时，累计字段可缺省，由计分器按 0 读取。记录保留 x、y、z、yaw、pitch、生命值、死亡计数、终止和跳变。死亡或控制阶段单步水平位移超过 2 格使回合失败，两种事件分别计数。布景命令和显式返回复位发生在控制轨迹范围以外。

新版实机负例用世界种子 `19961107` 的独立模拟器触发一次死亡。玩家从 `(-2587.5, -1507.5)` 重生到 `(-2205.5, -1125.5)`，距金柱 543.06 格。重生后生命值已为 20，累计死亡从 0 增到 1。计分器记录一条死亡和一条位姿跳变，回合判失败。该负例不计入重跑各组。[受控死亡复核](t1-respawn-tTWwXxTb/probe/summary.json)
