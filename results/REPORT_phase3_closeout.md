# 阶段 3 实验归档与结果分析

结论截至北京时间 2026 年 11 月 25 日 00:36。第二版 T1 上，共享同一份 LoRA 的无记忆组和学习式空间记忆组在正式 30 格评测中均为 **0/30**。按预先规则，本轮止损。独立的位姿折返对照在 30 和 100 格均为 **30/30**，表明记录的路线可用于执行长距折返。当前评测同时暴露了闭环动作偏置和目标紧邻出生点这两个问题。

## 3. 闭环为何掉到低位

**动作历史复制解释了原版的一类失败。** 原冻结训练索引的 57,549 条回程动作做量化档位往返，全部一致。原版正对金柱的失败复盘中，模型在首步生成右转，随后反复生成历史里的同一个动作。保持同一画面，仅把动作历史替换为空动作，输出从右转切为前进。固定的 JPEG 对照保持原输出。复制上一步动作在验证集已达到 2,258/2,401（94.04%），高于原末步两组的 88.25% 和 88.80%。原训练标签中前进占 90.18%，偏航中心档占 86.99%，因此总体动作匹配率容易被高频直行和重复动作主导。后续验证保留了 143 条动作变化样本的单独指标。 [动作与历史干预](REPORT_phase3_control_diagnostics.md#已验证的故障和原因) · [原始训练标签分布](t1-review-A8vp1K1p/screened_return_actions.csv)

**历史占位与 DART 改善了近距控制，但改善依赖检查点。** DART 冻结选取 50,000 帧，实机全量采集 422 个回合、140,288 帧。继续训练索引两种来源各取 6,000 个回程标签，DART 标签的偏航占比为 42.72%，原来源为 15.20%。首轮无记忆续训通过全部近距场景，空间组的偏角轨迹则基本复现恒定前进。随后平衡回放、偏航加权和同位置左右配对均未把两组一起推过预定门槛。完整候选动作的概率重排在六个检查画面中复现了原贪心方向。 [控制诊断与数据冻结](REPORT_phase3_control_diagnostics.md#修复运行)

| 近距版本 | 无记忆正对 / 可见偏角 / 视野外 | 空间记忆正对 / 可见偏角 / 视野外 |
| --- | --- | --- |
| 首轮占位 + DART，3,000 步 | 10/10，15/15，5/5 | 10/10，4/15，0/5 |
| 两来源平衡，1,000 步 | 10/10，8/15，0/5 | 10/10，4/15，0/5 |
| 均匀穿插可见场景与偏航加权，750 步 | 1/10，0/15，0/5 | 10/10，4/15，0/5 |
| 同场景直行、左右三联配对回放，256 步 | 3/10，0/15，1/5 | 0/10，0/15，0/5 |
| 共享首轮无记忆 LoRA | 10/10，15/15，5/5 | 10/10，14/15，5/5 |

共享 LoRA 空间组在近距的 2,302 步中左转 1,678 步、右转 0 步、前进 624 步。它能靠向同一方向扫视找到近距金柱。正式 30 格起点看不到金柱时，这个策略仍持续左转，已通过的近距门槛因而只能证明近距搜转和接近能力。 [共享 LoRA 的门槛判定](phase3-steering-paired-2AGguG2e/shared-adapter-probe/confirm-verdict.json)

## 4. 记忆存储、读取和可执行路线

| 诊断 | 测量结果 |
| --- | --- |
| 120 条冻结外出轨迹的网格审计 | 原 64 格宽网格在 10/30/60 格均保留起始停留段，100 格为 0/30。扩到 128 格后，100 格恢复至 30/30 |
| 完整历史 30 格单步干预 | 两个留出世界的四个状态，打乱视觉、清零视觉、旋转历史位姿或移除读取前缀后，贪心动作均与原条件相同，教师整动作匹配均为 2/4 |
| 完整历史 100 格扩容 | 一条 666 帧历史上，64 格宽只保留 0/40 个起始观测，128 格宽保留 40/40。首步生成动作相同 |
| 关键帧聚焦 | 在一个 30 格留出输入，将三张起始关键帧裁切到金柱附近。读取前缀相对变化约 0.0017%，首步动作相同 |
| 真值位姿闭环 | 直奔首个历史位姿在 30 和 100 格均为 0/30。沿历史路点折返两档均为 30/30，平均 260.1 和 585.8 步 |
| RGB 检索与路点折返 | 30/60/100 格的 14 个留出场景中，正确 RGB–位姿关联为 14/14，打乱关联为 3/14，直接选择第一个历史位姿为 14/14 |

原网格在 100 格确实会丢失最初的目标观测。扩容解决了这个存储问题。30 格的起始帧仍在网格内，完整历史干预也基本保留首步动作，定位到还要测量读取和控制之间的耦合。当前相对位姿只加到注意力的键，值来自视觉槽。当视觉投影近似相同时，位姿改变权重也难以改变读取结果。将位置嵌入加入值可让输出随位姿变化，该改动已通过读出和小模型训练验证。单步干预的样本量有限，正式闭环对照仍是当前版本的主结果。 [网格保留统计](phase3-memory-20261124/grid-retention/summary.json) · [完整 30 格干预](phase3-memory-20261124/heldout-d30-intervention/intervention.json) · [完整 100 格扩容](phase3-memory-20261124/heldout-d100-grid/intervention.json) · [冻结 LoRA 小模型测试](phase3-memory-20261124/frozen-controller-smoke/summary.json)

位姿折返用同一批冻结场景和归档的外出轨迹，输入是历史与当前的真值位姿。金柱坐标用于评分。粗容差下许多回合在 3.03 格左右提前停住，末段减速并把容差从 0.4 收紧到 0.1 后，两档均达到 30/30。这个结果给出了可执行的控制方案。120 个冻结回合的首条位姿都在距金柱 2.828 格处，因此当前场景允许仅靠起点位置找到成功区域。RGB 检索对打乱配对很敏感，其相对仅用位姿的增益仍需要用目标远离起点的布景来检验。 [折返逐回合记录](phase3-memory-20261124/pose-controls-archived/episodes.csv) · [RGB 检索闭环](phase3-memory-20261124/rgb-pose-replay/episodes.csv)

## 5. 下一轮应检验什么

1. **让记忆输出可执行路点。** 固定已通过导航门槛的 LoRA 和统一的局部执行器，监督空间读取选择下一个历史路点。先对齐几何与动作、跑短距闭环，再用未参与训练的种子评测 30 格。100 格应保留目标关键帧或扩大物理网格，同时复测行为是否随历史内容改变。
2. **在独立布景上测语义检索。** 将出生点移出所有候选目标的 3 格成功半径，让同一条路线经过几何相同的两个候选地标。配对场景交换目标与干扰物，维持相同的回程起点和遮挡。用相同执行器比较真实视觉与位姿、打乱配对、只有位姿和无记忆四种输入，另复核预算内逐个搜索的捷径。
3. **把控制验收放在开环指标前。** 同时记录左右转向、动作变化处准确率、近距偏角门槛、回程最小距离和路径长度。三轮短续训的差异提示只优化平均交叉熵或扩大同类回放，容易把策略推向另一种单一动作。
